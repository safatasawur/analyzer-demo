JS Info Flow

A small static analyzer that follows sensitive data, such as a password read by readPassword(), through variables and function calls, and reports when it reaches a sink like console.log. The code you submit is parsed, never run.

How it works

  1. parse

    Acorn turns the source into an abstract syntax tree. Nothing is executed.

  2. register

    Top-level function declarations are collected so their bodies can be analyzed per call.

  3. track

    Top-level statements are walked in order. A variable becomes tainted when its declaration contains a source call or another tainted value.

  4. follow calls

    For calls to known functions, tainted arguments mark parameters, local declarations propagate, and the first top-level return decides whether the result is tainted.

  5. report

    Any call to a configured sink with a tainted argument becomes a finding, recorded once per sink and line.
